利用規約

制定日: 2026年11月12日

1. 対象

sns-hub（以下「本ツール」）は、運営者（なかあき）本人が自分のアカウントへ動画を投稿するためだけに使う個人用ツールです。一般の方への提供や販売は行っていません。

2. 利用者

本ツールを使えるのは運営者本人だけです。第三者のアカウントへの投稿には使いません。

3. 各サービスの規約の遵守

本ツールの利用にあたっては、YouTube 利用規約、Google API サービス利用規約、Instagram 利用規約・Meta プラットフォーム規約、TikTok 利用規約・TikTok for Developers 規約を守ります。

4. 投稿内容

投稿する動画とその内容の責任は運営者にあります。本ツールは、運営者が確認・承認した投稿だけを送信します。

5. 免責

本ツールは現状のまま提供され、各サービスの仕様変更などにより動作しなくなる場合があります。

6. 改定

本規約を変更する場合は、このページを更新します。
