プライバシーポリシー

制定日: 2026年11月12日

sns-hub（以下「本ツール」）は、運営者（なかあき）本人が自分のアカウントへ動画を投稿するためだけに使う個人用ツールです。本ポリシーは、本ツールが Google（YouTube）などのアカウント情報をどう扱うかを説明します。

1. 利用する情報

本ツールは、Google の OAuth 認証で許可された範囲（YouTube Data API の youtube.upload：動画のアップロード）だけを利用します。チャンネルの視聴データ、連絡先、メール、その他の個人情報は取得しません。

2. 情報の使い道

許可された権限は、運営者が指示した動画を、運営者自身のチャンネルへアップロードするためだけに使います。広告、分析、販売などには使いません。

3. 保存場所

認証で得たトークンは、運営者のパソコン内（Windows の資格情報マネージャー）にだけ保存します。外部のサーバーには保存しません。

4. 第三者への提供

取得した情報を第三者に提供・共有・販売することはありません。

5. Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の利用および他のアプリへの転送は、Google API Services User Data Policy（限定的使用の要件を含む）に従います。

6. 許可の取り消し

Google アカウントの サードパーティのアクセス 画面から、いつでも本ツールへの許可を取り消せます。取り消すと、保存済みのトークンは使えなくなります。

7. 改定

本ポリシーを変更する場合は、このページを更新します。
